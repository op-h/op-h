## How I work

I start at the alert and walk it back until I find the cause.

```
ALERT  → triage in the SIEM: Splunk, Elastic, Snort
TRACE  → hunt through packets, memory and disk: Wireshark, eCTHP, eCDFP
CAUSE  → rebuild the attacker's path with MITRE ATT&CK and contain it: eCIR
BUILD  → turn what I learn into a tool
```
